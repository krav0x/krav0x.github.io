Portuguese Accounting LLM

In development

RAG system over Portuguese tax law: CIRS, CIRC, CIVA, and AT circulars. Architecture separates knowledge (RAG), behavior (LoRA fine-tuning if needed), and computation (always deterministic code). Three autonomy tiers, with AT submissions always requiring human approval. Portuguese open model candidates: Amália (EuroLLM-9B) and EuroLLM-22B.

SAF-T PT Invoice Analysis

Shipped, used by my practice

Web app that parses and classifies SAF-T PT files (Portugal's standard audit file for tax) for multi-company, multi-store operations. Handles 30 to 50 MB XML streams in-browser via a Web Worker. Includes fiscal classification (JOGOS, TABACO, IVA, SERVIÇOS, REVISÃO) and a scratch card commission calculator that replaced my old Excel model. Monetary values stored as bigint cents throughout.
