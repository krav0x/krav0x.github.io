01 · About

The bridge from books to models

I spent nine years as a Certified Accountant in Portugal, working across a portfolio that ranged from micro companies to businesses turning over €40M a year. That gave me a working knowledge of Portuguese tax code, SAF-T, IRS Modelo 3, VAT regimes, and the operational reality of running finance for real businesses at very different scales.

Since then I've been rebuilding my toolkit around ML and data engineering, currently interning as a Data Scientist at Moongy while finishing a Master's in Data Science at ESCE-IPS. My angle is the intersection: domain-specialised ML systems for Portuguese accounting and tax, where a generic model will confidently paraphrase the wrong article and the correct answer is worth money.

Portuguese Accounting RAG

Portuguese-language RAG over CIRS, CIRC, CIVA, RITI, LGT, EBF, SNC, NCRF. 4,448 article-level chunks in Chroma, queried via MiniMax M3 on OpenRouter. CineMatch

Movie recommender on the MovieLens 25M dataset. SVD collaborative filtering plus TF-IDF content-based, evaluated with Precision@10 and NDCG@10 on a temporal train/test split. TMDb API enrichment (posters, descriptions), deployed as a Netflix-inspired Streamlit app.

Steam Game Recommender

Content-based recommender over ~5,000 games using SteamSpy tag data. TF-IDF plus cosine similarity on a sparse feature matrix pipeline, exposed via a FastAPI REST endpoint supporting multi-game queries by averaging feature vectors. Backend on Render, frontend on Vercel.

// Python · FastAPI · scikit-learn · React · Vite

Live demo ↗ GitHub ↗

PySpark Fraud Detection

End-to-end PySpark pipeline on Databricks for credit-card fraud detection. Compared Logistic Regression, GBTs, Random Forest, and a Neural Network under class-imbalanced data. StandardScaler + log-transform preprocessing, cross-validation for hyperparameter tuning, AUC / precision / recall / F1 evaluation. Best model persisted to DBFS.

// Python · PySpark · MLlib · Databricks

Transformer from scratch

Built and trained a Transformer end to end as part of structured Python and ML self-study. Multi-head attention, positional encodings, encoder-decoder stack, training loop, and inference implemented from first principles rather than assembled from library primitives.
